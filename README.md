## Retail Discount Engine

A lightweight retail pricing simulation that applies category-based discounts, customer-specific price adjustments, and inventory-based checkout cycles. This repository demonstrates JavaScript control flow, data modeling, and DOM-free interaction through console output.

---

## Features

- Applies discount rules by product category
- Calculates additional customer discounts for roles such as `student` and `senior`
- Simulates inventory consumption across multiple checkout cycles
- Outputs total purchase amounts and product details to the browser console

---

## Project Structure

- `index.html` - Minimal HTML wrapper that loads the JavaScript demo
- `cc_4.js` - Main script containing product definitions, discount logic, inventory simulation, and console output
- `README.md` - Project overview and usage instructions

---

## How to Run

1. Open `index.html` in a web browser.
2. Open the browser console (usually `F12` or `Ctrl+Shift+I` / `Cmd+Option+I`).
3. Observe the pricing and inventory output generated by the script.

---

## Implementation Details

- Product data is defined as an array of objects with `name`, `category`, `price`, and `inventory`
- Discount rates are determined using a `switch` statement by category
- Additional customer discounts are handled with conditional logic
- The simulation runs three customer checkout cycles, decrementing inventory each time
