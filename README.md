# Retail Discount Engine

A small simulation that applies retail discount rules, customer pricing tiers, and inventory tracking in a browser demo.

## Technologies Used

- HTML
- JavaScript

## What This Project Does

- Defines a product catalog with categories, prices, and inventory counts
- Calculates category-based discounts for electronics, apparel, groceries, and household goods
- Applies an additional customer discount for roles such as `student` or `senior`
- Simulates multiple checkout cycles and reduces inventory as items are sold
- Renders the simulation summary in the browser and logs it to the console

## How to Run

1. Open `index.html` in a web browser.
2. The application runs automatically and displays output in the page.
3. Optionally open the browser console to view the same log messages.
